When a user visits the landing page for the first time, they must sign up by clicking the “Let’s Start” button. After signing up using their email or Google or Apple account, they will be redirected to the Shop Wizard, since they haven’t created a shop in CeyPOS yet. Once the shop creation process is completed, a dedicated database file will be generated in the /database folder, uniquely associated with the user’s account. The file name will follow the format: useremail+uniqueShopID.db (e.g., ceypos@gmail.com_id13245.db). All data related to that specific shop will be stored in this database file permanently, this exact database file will be used for the shop for forever. Only after the database file is successfully created should the user be redirected to the dashboard. The system will store user details such as email and database file name in Clerk for validation purposes. When the user returns to log in, they should only be granted access to the dashboard if these validations pass: (1) the user has successfully signed up and completed the shop creation process through Clerk (meaning both a user account and shop exist), and (2) the corresponding database file for that shop actually exists in the backend /database file in folder- if the file does not exissts, system should never create a new database file for the shop at that time, only if the exact file is exissts user will be directed to the dashboard. Only when both of these conditions are verified should the user be allowed to access their dashboard.
